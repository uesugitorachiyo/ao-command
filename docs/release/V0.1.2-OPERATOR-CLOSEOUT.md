# AO Command v0.1.2 Operator Closeout

AO Command v0.1.2 extends the public, read-only operator surface for current AO
Mission, Atlas, Forge, Covenant, AO2, and Control Plane evidence. It remains a
consumer of producer-owned truth and does not gain execution or publication
authority.

## Release Notes

- Read current Mission lifecycle and canonical Atlas terminal-index evidence
  with strict source, state, digest, and correlation checks.
- Present governed GitHub issue-repair and package qualification state without
  converting readbacks into mutation authority.
- Reject stale, contradictory, malformed, private, or over-authority producer
  packets before rendering a ready state.
- Preserve deterministic JSON and terminal views across restart, compaction,
  replay, and duplicate-delivery evidence.
- Build and smoke-test native Linux, macOS, and Windows candidates with exact
  source, version, release-notes, manifest, and workflow provenance.

## Ready Scope

- Inspect AO Stack status and retained evidence supplied by an operator.
- Validate bounded producer documents against their published contracts.
- Render Mission, Atlas, Foundry, Forge, Covenant, AO2, and Control Plane
  readbacks without becoming a source of domain truth.
- Assemble and verify an immutable release plan in dry-run mode.
- Report exact build identity through `ao-command version --json` without
  provider calls or repository mutation.

## Out Of Scope

- Approving or scheduling work, executing patches, or mutating repositories.
- Publishing without exact live inputs and protected-environment approval.
- Promoting production or changing provider, credential, or policy state.
- Accepting unbound or substituted producer evidence.

## Required Evidence Before Tagging

Run the repository Go gates, the credential-free AO Command smoke, and the
production-readiness audit from a clean exact-head worktree. The audit must
report `status=passed`, `readiness_percent=100`, and `failed_checks=0`.

The canonical release rehearsal must run with `version=0.1.2`, `tag=v0.1.2`,
the exact source commit, the exact source-owned closeout notes, the approved
manifest, and `dry_run=true` before any live publication. The rehearsal must
record that tag creation, release creation, public upload, deployment, and
provider calls were not attempted.

## Publication State

This closeout does not create a tag or GitHub release. Publication remains a
separate protected job in `.github/workflows/release-rehearsal.yml` and must
consume the immutable verified rehearsal plan.

## Safety Boundaries

- Operator commands remain read-only and provider-free.
- Dry runs do not create tags, releases, uploads, or deployments.
- The publisher requires exact source, manifest, candidate, source-owned notes,
  and plan bindings plus explicit protected-environment approval.
- Public retained evidence remains governed by the repository provenance
  contract.
